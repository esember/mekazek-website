Overview

Learn the Words That Matter Most

Flashcard-style app for learning the 2,000 most frequently used B2 & C1 English words. Features text-to-speech, auto-timer, alphabetical index, level filtering, and bilingual (Turkish + English) display.

Personal Project  ·  Vanilla JS · Tailwind CSS · Web Speech API  ·  Built 2025
Features

Built for Real Study Habits

No backend, no build step — just a fast, focused vanilla JS app that runs entirely in the browser.

  • Text-to-Speech — every word can be heard aloud via the Web Speech API, reinforcing pronunciation alongside spelling.
  • Auto-timer — flashcards can auto-advance on a timer for hands-free repetition drills.
  • Alphabetical index — jump directly to any word without scrolling through the full list.
  • Level filtering — study B2 and C1 vocabulary separately or together.
  • Bilingual display — Turkish and English shown side by side for every entry.
